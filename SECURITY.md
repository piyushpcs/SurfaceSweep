# Security Policy

## Supported versions

Only the latest commit on `main` is supported. Report issues against `main`.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report privately via:

- GitHub Security Advisories: https://github.com/piyushpcs/SurfaceSweep/security/advisories/new
- Or email the maintainer listed on https://github.com/piyushpcs

Include:

- Affected version / commit SHA
- Steps to reproduce
- Impact (e.g. SSRF, path traversal, secret exfiltration, RCE)

You should receive an acknowledgment within a few days. Confirmed issues get a fix and credit (unless you prefer anonymity).

## Scope notes

SurfaceSweep is a **recon and scanning** tool. Findings about third-party targets scanned with this tool are out of scope for this repo — report those to the target's own security contact.
